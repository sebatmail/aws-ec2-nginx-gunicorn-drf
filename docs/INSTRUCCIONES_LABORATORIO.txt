PASO 5: MODELO, SERIALIZADOR Y VISTAS
Editar tasks/models.py:
--------------------------------------------------
from django.db import models

class Task(models.Model):
    title = models.CharField(max_length=200)
    done = models.BooleanField(default=False)

    def __str__(self):
        return self.title
--------------------------------------------------

Editar tasks/serializers.py:
--------------------------------------------------
from rest_framework import serializers
from .models import Task

class TaskSerializer(serializers.ModelSerializer):
    class Meta:
        model = Task
        fields = '__all__'
--------------------------------------------------

Editar tasks/views.py:
--------------------------------------------------
from rest_framework import viewsets
from .models import Task
from .serializers import TaskSerializer

class TaskViewSet(viewsets.ModelViewSet):
    queryset = Task.objects.all()
    serializer_class = TaskSerializer
--------------------------------------------------

Editar todolist_project/urls.py:
--------------------------------------------------
from django.contrib import admin
from django.urls import path, include
from rest_framework import routers
from tasks.views import TaskViewSet

router = routers.DefaultRouter()
router.register(r'tasks', TaskViewSet)

urlpatterns = [
    path('admin/', admin.site.urls),
    path('api/', include(router.urls)),
]
--------------------------------------------------

Editar todolist_project/settings.py:
- Modificar: ALLOWED_HOSTS = ['*']

    'tasks',

    STATIC_URL = '/static/'
    STATIC_ROOT = '/home/ubuntu/apps/static/'

PASO 9: CREAR SERVICIO GUNICORN
sudo nano /etc/systemd/system/gunicorn.service
Pegar:
--------------------------------------------------
[Unit]
Description=Gunicorn daemon for Django ToDoList
After=network.target

[Service]
User=ubuntu
Group=www-data
WorkingDirectory=/home/ubuntu/apps
ExecStart=/home/ubuntu/apps/venv/bin/gunicorn --workers 3 --bind unix:/home/ubuntu/apps/todolist.sock todolist_project.wsgi:application

[Install]
WantedBy=multi-user.target
--------------------------------------------------

Iniciar Gunicorn:
sudo systemctl daemon-reload
sudo systemctl start gunicorn
sudo systemctl enable gunicorn

PASO 10: CONFIGURAR NGINX COMO PROXY INVERSO
sudo nano /etc/nginx/sites-available/todolist
Pegar:
--------------------------------------------------
server {
    listen 80;
    server_name _;

    location /static/ {
        alias /home/ubuntu/apps/static/;
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/home/ubuntu/apps/todolist.sock;
    }

    error_log /var/log/nginx/todolist_error.log;
    access_log /var/log/nginx/todolist_access.log;
}
--------------------------------------------------

Activar sitio y reiniciar Nginx:
sudo ln -sf /etc/nginx/sites-available/todolist /etc/nginx/sites-enabled/todolist
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl restart nginx
